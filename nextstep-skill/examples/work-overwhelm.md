# Example — Work overwhelm

## Input

I need to finish slides for tomorrow, answer a non-urgent message, organize files, and think about whether I should change jobs.

## Output

**Do now:** Finish the first complete draft of tomorrow's slides.

**Why:** It has the nearest real deadline and delaying it creates avoidable pressure.

**Ignore for now:** The job-change question. It matters, but it does not require a decision tonight.

**Then:** Reply to the message if there is still time.
