# Publication Figure Checklist

- [ ] Readable at final manuscript width
- [ ] Axis labels complete and unclipped
- [ ] Font sizes consistent across panels
- [ ] Legends outside dense data regions
- [ ] Groups distinguishable in grayscale
- [ ] Line widths and marker sizes consistent
- [ ] Error bars or confidence intervals visible
- [ ] Units shown
- [ ] Subplot labels aligned
- [ ] Unnecessary borders and grid lines removed
- [ ] PDF or SVG exported
- [ ] PNG at 600 dpi when raster output is required
- [ ] Scientific meaning preserved
